# Personal Finance API

API para gerenciamento de finanças pessoais.

## Status

Projeto em fase inicial — apenas a estrutura de repositório foi configurada até o momento.

## Requisitos

- Python 3.11+

## Setup

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Variáveis de ambiente

As configurações sensíveis ficam em um arquivo `.env` na raiz do projeto (não versionado).
